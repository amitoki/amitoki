# amitoki 0.1.0

amitokiとして最初の公開リリースです。解析・フィルタを自作ブロックとして追加し、複数の中継先と組み合わせられます。本体はループ対策、NIC、配送ID・ACK、キューと実行上限を管理します。

- `plugin relay|block add/update/del`でGitHub URL、配布ディレクトリ、追加済みの名前を指定できます。本体の再ビルドは不要です。
- `plugin block test`と`debug replay/compare`でPCAPを使った単体テスト、経路の確認、修正前後の比較ができます。
- `plugin block watch`で変更を検知し、指定したビルドとPCAPテストを繰り返せます。`--once`はCIでも利用できます。
- Linux x86_64・ARM64向けに本体のtar.gz・debとSHA256SUMSを配布します。プラグインは別途追加します。

[インストール](https://github.com/amitoki/amitoki/blob/v0.1.0/docs/releases.md)、[ブロック構成](https://github.com/amitoki/amitoki/blob/v0.1.0/docs/block-pipelines.md)、[プラグイン開発](https://github.com/amitoki/amitoki/blob/v0.1.0/docs/plugin-development.md)を参照してください。

stegrdbから引き継いだ`[relay]`設定と種類を省略したプラグイン管理CLIは引き続き利用できます。PCAPNG、稼働中パイプラインのホットリロード、GUI、ブラウザWebRTCは今回の対象外です。
